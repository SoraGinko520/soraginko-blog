# 隐私说明

SoraGinko 的个人博客位于 https://soraginko.moe。

## 评论与留言

评论服务使用 Waline，数据存储在 Neon PostgreSQL，服务部署在 Vercel。提交留言时，服务可能处理昵称、邮箱、网站地址、留言内容和 IP 地址；邮箱用于评论身份和头像功能，不在公开留言中展示。IP 地址可能用于防止刷屏与滥用，不能因为地区和设备信息不公开展示就理解为服务不处理这些数据。

当前允许匿名评论，不要求使用社交账号登录。所有新评论需经管理员审核后才公开。请不要在评论正文中提交密码、证件信息或其他敏感个人信息。

## 本地存储与第三方资源

站点可能在浏览器中保存主题、评论会话、昵称和留言草稿等设置。头像、表情、网站导航图标等外部资源的提供方可能收到访问请求。

本站使用 iBruce 原版不蒜子（`busuanzi.ibruce.info`）展示首页访客数、浏览量和文章阅读量。正式域名下不含查询参数的页面访问会向该服务发送一次 JSONP 计数请求，通过 HTTPS Referer 传递当前站点及页面路径，供服务区分文章；浏览器不会在 Referer 中发送 URL 锚点。为避免外发查询参数，带查询参数的页面不发送计数请求。本地及预览域名也不计数。该服务可能处理请求 IP、User-Agent 等网络信息，浏览器对第三方 Cookie 的限制由其自身策略决定。本站不额外提交表单、留言内容或登录凭据。公共统计结果不代表永久识别的独立真人，可用性及数据保存由提供方决定。

按站长要求，首页及文章累计显示值为固定历史基数加上新服务返回值：访客加 189、浏览加 670、首篇文章阅读量加 34。历史基数由站长提供，原统计截止时间未确认；它只在本站前端参与加法，没有从原服务恢复或导入新服务数据库，也不包含可恢复的访客明细。跨服务 UV 没有去重，旧、新统计可能包含同一访客，累计访客数不代表跨服务去重人数。新请求加载中或失败时仅显示历史基数，并注明状态，不将未知新增计数当作零或虚构增长。

Umami Cloud 追踪脚本仍用于独立的访问与出站链接分析，公开统计通过分享页查看。Umami 与不蒜子采用不同统计口径，数字不能混用；不会抓取 Umami 分享页内容或通过其非公开、付费接口取数。会话回放保持关闭。

当前未启用 Google Analytics、Microsoft Clarity、51LA 或评论浏览量统计，也未配置评论邮件通知。托管和安全服务仍可能产生常规访问日志。
